JustType is a simple and interactive typing practice application designed to help users improve their typing speed, accuracy, and consistency.
Users can choose between 1-minute, 3-minute, or 5-minute typing tests and type the given text within the selected time limit. During the test, the application tracks performance metrics such as WPM, accuracy, completed words, and typing errors.

Features:

  • ⏱️ 1, 3, and 5-minute typing tests
  • ⌨️ Real-time typing practice
  • 📊 WPM and accuracy tracking
  • ❌ Error tracking
  • 🎯 Helps improve typing speed and accuracy
  • 📱 Responsive and clean user interface
  • ⚡ Fast and lightweight frontend application

Built with:

HTML, Tailwind CSS, JavaScript, and JQuery

Purpose:

JustType was created as a frontend development project to practice UI design, DOM manipulation, event handling, timers, JavaScript logic, and responsive web design.
